# 3. How to Select Auto

1. Open Elastic

If the widget for the "Auto Selectable" A.K.A. auto selection **IS NOT** there

2. Add widget
3. Select Tunables dropdown menu
4. Put the Auto Selectable onto the grid
5. Use the Selectable to choose the auto

If the widget for the "Auto Selectable" **IS** there

2. Use the Selectable to choose the auto

# 4. Tips

* Use field and camera widget to make sure the robot is accurate for auto-align, PathPlanner, etc.
